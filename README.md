## ⭐️⭐️ 프로젝트 기여 부분 ⭐️⭐️<br>
● &nasp;동네생활(커뮤니티)<br>
1. &nasp;커뮤니티 리스트,상세페이지 출력<br>
2. &nasp;커뮤니티 등록(회원가입 한 경우),수정/삭제(내가 쓴글일 경우)기능<br>
3. &nasp;키워드 검색<br>
4. &nasp;하단 페이징 처리<br>
5. &nasp;계층형 댓글구현<br>
6. &nasp;공감하기 버튼<br>
7. &nasp;수정폼에 기존 이미지 미리보기출력

● &nasp;마이페이지(내상점, 판매내역, 나의후기, 관심상품)<br>
1. &nasp;나의 닉네임,프로필 이미지 수정<br>
2. &nasp;판매내역 상태별 리스트 출력<br>
3. &nasp;내가 쓴 후기 리스트 출력<br>
4. &nasp;좋아요 한 상품 리스트 출력, 삭제
